## 🧸 About Me

> **집요한 책임감으로, 문제를 구조적인 개선으로 연결합니다.**

프론트엔드 개발 과정에서 단순히 화면을 구현하는 것보다  
**사용자가 어떤 흐름으로 서비스를 경험하는지**,  
그리고 **팀이 같은 기준으로 지속적으로 개발할 수 있는지**를 함께 고민합니다.

- 🧩 반복되는 UI와 설정을 **공통 패키지와 Storybook**으로 정리해 팀의 개발 기준을 맞췄습니다.
- ⚡ 대용량 이미지·영상이 포함된 서비스에서 **S3 · CloudFront 기반 전달 구조와 로딩 전략**을 개선했습니다.
- 🗂️ React Query를 활용해 API 호출과 캐시 관리 기준을 정리하며 **복잡한 데이터 흐름을 구조화**했습니다.
- 🤝 팀 프로젝트에서는 기능 구현뿐 아니라 **요구사항, 역할, 우선순위와 작업 기준을 정리하는 일**에도 적극적으로 참여합니다.
- 🤖 최근에는 AI 에이전트를 개발 과정에 활용하면서 **요구사항 → 계획 → 구현 → 검증** 과정을 더 체계화하고 있습니다.
